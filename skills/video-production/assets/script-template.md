## مدخلات المانيفست

كل عنصر في الفصل ده بيتسجّل:

```json
{ "id": "", "type": "text|ui|number|shape|image",
  "zone": "", "bbox": [x0,y0,x1,y1],
  "frames": [start,end], "still_from": 0,
  "chapter": "", "critical": true, "texture": false }
```

`texture: true` = نسيج بصري **مش مقصود للقراءة** — بيستثنيه من فحص زمن القراءة.
**استخدامه لازم يتبرر هنا صراحةً** ومعاه مواصفة بتمنع محاولة القراءة (حجم صغير · شفافية منخفضة · في الركن) `#31`.

```json
{ "id": "", "frames": [start,end], "magnitude": "large|small" }
```

## التنفيذ

1. **افحص البيانات التجريبية** — مفيش ملكية فكرية للغير `#17`
2. ابني **`ZoneGuard` أولاً** — بيرفض الرسم برّه المنطقة **وبيكتب المانيفست**
3. نفّذ الفصول من الأبسط للأعقد
4. **نسبة واحدة · صامتة · وقف** `#36`
5. شغّل `verify.mjs` — **لازم يعدّي قبل ما المستخدم يشوف** `#35`

```bash
node scripts/verify.mjs --video out.mp4 --manifest layout.json --config brand.json
```
